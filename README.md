# Growfinix-Internship-ML-Task5-Power-Consumption-Forecasting
Machine Learning project for forecasting electricity power consumption using Python and Linear Regression as part of the Growfinnix Machine Learning Internship.

# Power Consumption Forecasting using Machine Learning

## Growfinix Machine Learning Internship

### Task 5: Energy - Power Consumption Forecasting

---

## Objective

The objective of this project is to forecast future electricity power consumption using historical monthly power usage data. Power forecasting helps energy providers plan electricity generation and distribution efficiently.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn

---

## Machine Learning Model

* Linear Regression

---

## Project Workflow

1. Import the required libraries.
2. Create a sample dataset representing five years of monthly power consumption.
3. Check the dataset for missing values.
4. Convert the month values into numerical features.
5. Train the Linear Regression model.
6. Predict the power consumption for the upcoming month.
7. Display the prediction and task completion message.

---

## Output

The program displays:

* First five rows of the dataset
* Missing value information
* Predicted power consumption for the next month
* "Task Completed Successfully!" message
